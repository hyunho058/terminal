#   NOT equivalent, so by CLAUDE.md's rule they are missing tests rather than noise. What
#   they cost was checked rather than assumed, and it is why they are recorded instead of
#   killed here. Reaching either mutant needs a NON-EMPTY roster, because with an empty one
#   the `SetActive` arm's `roster.iter().find(..)` yields `None` and the whole block is
#   skipped. A non-empty roster makes `deriver.tab()` run for a real pid, and distinguishing
#   the correct tab from the wrong one needs two tabs that derive to DIFFERENT metas — with
#   every tab deriving to `TabMeta::default()` the mutants are observationally identical.
#   So a test would have to read the live process table, which is the class of test this repo
#   has already been bitten by (a machine-dependent failure reads as your regression). The
#   alternative is injection, and `run` builds its own `Deriver::new()` internally while the
#   seams tests use — `cwd_of`, `agent_of`, `start_ms_of` (worker.rs:697-701) — are fields on
#   a Deriver the caller owns. Injecting would mean changing `run`'s signature: a production
#   change, on a path this feature never touched, to cover a pre-existing gap.
#   If they are ever killed, that is the shape it takes.
