# file previously made — recorded rather than deleted, because the wrong reasoning is the
# part worth keeping:
#
#   1. `replace run with ()` survived, which meant no test executed a single statement of
#      the worker loop: the two lines that turn an armed deadline into a wake could be
#      deleted with all 769 tests green and this whole feature inert. Killed by the
#      `r3_1_r3_5` test, which drives the real loop over an empty roster so every iteration
#      is command-driven — no process walks, no ticks to wait out, no sleeps.
#
#   2. Two more survived in the `Cmd::SetActive` arm (`tp.id == id` and the published-slot
#      lookup beside it, both pre-existing, authored by 27716e0f / f9ffb581). This file
#      previously recorded them as effectively unkillable: reaching them needs a non-empty
#      roster, a non-empty roster makes `Deriver::tab` walk a real process tree, and telling
#      the right tab from the wrong one appeared to need two tabs deriving to different
#      metas — so a test would have to read the live process table, and the only alternative
#      looked like changing `run`'s signature to inject a `Deriver`.
#
#      **That analysis was wrong, and it was wrong in a specific, repeatable way: it treated
#      the code's shape as fixed and asked only what a test could reach.** The third option
#      is to move the decision to where a test already is. Both mutants were pure logic —
#      "which rostered tab does this id name" and "which published slot does it update" —
#      tangled into a loop that also does I/O. Extracted as `rostered` and `upsert_meta`,
#      they are testable with no clock, no processes and no thread, which is the same move
#      `publish_if_changed` already documents for the differ ("a free function so the differ
#      is unit-testable without the thread"). The refactor preserves behaviour exactly.
#
#      The general lesson, and the reason this paragraph stays: "no test can reach it" is a
#      statement about the code's shape, not about the test suite. Reach for the shape before
#      concluding a survivor is too expensive to kill.
